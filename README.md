# KOL 邮件生成器 / KOL Email Generator

一个免费、专业的 KOL 合作邮件生成工具，支持多语言，一键生成标准商务邮件。

## ✨ 功能特点

- 🌍 **多语言支持**：中文 / English / 日本語 / Français / Español / 한국어
- 📧 **5大合作场景**：合作邀约 / 样品寄送 / 内容审核 / 合作致谢 / 续约合作
- 🤖 **智能识别**：自动检测语言，自动提取收件人名称
- 📋 **一键操作**：复制全文、下载 .txt 文件
- 📱 **响应式设计**：手机、电脑都能完美使用

## 🚀 使用方法

直接打开 `index.html` 即可使用，无需安装任何软件。
